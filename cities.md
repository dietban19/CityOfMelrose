# City of Edmonton Website Technology Stack

The City of Edmonton website appears to use the following technologies.

## Core Platform

- **CMS:** Drupal 10
- **Backend language:** PHP
- **Web server:** Apache HTTP Server
- **Cloud infrastructure:** Amazon Web Services and Google Cloud

## Frontend

The website does not appear to be primarily built with React, Vue, or Angular.

It uses **Handlebars** for templating and several traditional JavaScript libraries:

- jQuery
- jQuery UI
- DataTables
- Select2
- Splide
- FancyBox
- Moment.js
- JSZip
- core-js
- Font Awesome

## Forms and Media

- **Form builder:** FormAssembly
- **Video players:** YouTube and MediaElement.js
- **Electronic documents and signatures:** DocuSign

## Performance and Content Delivery

The website uses several content delivery networks and cloud services:

- Cloudflare
- Amazon S3
- Google Cloud CDN
- cdnjs
- jsDelivr

It also supports **HTTP/3**.

## Security

- Cloudflare Bot Management
- Google reCAPTCHA
- TLS 1.3
- SPF email authentication
- DMARC email authentication

## Analytics and Monitoring

- Google Analytics
- Google Tag Manager
- Crazy Egg
- Siteimprove

## Summary

Edmonton.ca is an enterprise website built mainly with **Drupal 10 and PHP**.

Its frontend uses a custom Drupal theme, Handlebars templates, jQuery, and several reusable JavaScript components. It is not primarily a React, Vue, or Angular application.

The website also relies on cloud hosting, CDNs, third-party forms, analytics tools, accessibility monitoring, and security services.
